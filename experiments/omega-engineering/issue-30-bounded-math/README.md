# clamp

Clamps a number within inclusive lower and upper bounds.

## Usage

```javascript
import { clamp } from './index.mjs';

clamp(5, 0, 10);  // 5
clamp(-5, 0, 10); // 0
clamp(15, 0, 10); // 10
```
