# Gravity Jump Canvas Prototype

Native Android Java 17 Canvas prototype, no webview and no third-party dependencies. Gradle AGP 8.7.3, compile SDK 35.

Build on a machine with Android SDK 35, JDK 17 and Gradle 8.9: `gradle assembleDebug`. Output: `app/build/outputs/apk/debug/app-debug.apk`.

Only Android CI/device tests can prove an installable APK. Template generation is not equivalent to a verified build.
