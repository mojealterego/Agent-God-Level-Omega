# OMEGA Agent Teams v4.1.0

OMEGA uses 165 specialized agent skills grouped into six production teams. They are role-specific skill contracts coordinated hierarchically; this is not a claim that 165 model processes run simultaneously.

Teams: core-control-plane (21), code-lifecycle (10), android-native (30), web-e2e (30), aaa-game (68), multicloud-ai (6).

The multi-cloud team routes Google Cloud/Gemini Vertex AI and IBM Cloud/watsonx alongside the existing OpenAI, GitHub/GitLab, Unity, Google Play and Termux lanes.
