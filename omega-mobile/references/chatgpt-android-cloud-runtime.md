# ChatGPT Android cloud runtime

OMEGA Mobile uses provider-native cloud execution as the default on the ChatGPT Android app. GitHub/GitLab handle source and CI; cloud runners build Android APK/AAB; Unity Build Automation handles Unity builds; Google Play Publisher handles release edits; OpenAI provider tools handle supported OpenAI operations. The Secure MCP Tunnel to Termux is optional and adds local/device execution when connected.
