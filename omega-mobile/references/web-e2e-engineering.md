# Web E2E engineering

The web team covers product architecture, frontend frameworks, backend services, API contracts, persistence, auth, payments, realtime systems, AppSec, accessibility, Core Web Vitals, PWA/offline behavior, observability, browser E2E and release verification.

Provider-native GitHub/GitLab CI remains the default cloud execution authority from ChatGPT Android. Browser E2E uses project-native Playwright/Cypress/Webdriver configuration when present; OMEGA never invents a passing browser test from source inspection alone.
