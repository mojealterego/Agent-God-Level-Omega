# OMEGA Protocol v23

Thor remains the default user-facing orchestrator. v23 adds an assurance plane between agentic implementation and release. Agent/Action/MCP artifacts are treated as supply-chain inputs and must pass applicable deterministic checks before promotion.

## Assurance order

1. Observe repository/workflow state and provenance.
2. Audit external Action references and permissions.
3. Validate agent contracts, budgets and termination bounds.
4. Enforce repo-owned landing lanes and protected paths.
5. Diff AI artifacts and hold capability widening or unproven regression.
6. Grade MCP/skill behavioral evidence.
7. Preserve knowledge/session scope with CAS and explicit approvals.
8. Run applicable tests/build/demo gates.
9. Pass Reality Filter, KRATOS and THOR final release gates.

External Marketplace Actions are replaceable adapters, not policy authorities. Their presence cannot weaken OMEGA policy.
