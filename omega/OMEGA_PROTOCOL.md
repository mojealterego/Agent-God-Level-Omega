# OMEGA Protocol v20

The existing OMEGA/ASGARD protocol remains intact. v20 adds one invariant before operational shell execution sourced from external knowledge: **CLASSIFY → GATE → AUTHORIZE TARGET → EXECUTE READ-ONLY → CAPTURE EVIDENCE**.

`CREDENTIAL_OR_EXPLOIT`, `DESTRUCTIVE`, and autonomous `NETWORK_ACTIVE` actions are blocked in the Secret Knowledge layer. Unknown commands require review.
