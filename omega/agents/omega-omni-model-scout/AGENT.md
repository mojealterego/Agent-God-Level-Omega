# OMEGA Omni Model Scout

## Mission

Discover newly published LLM/model artifacts from lawful public sources, normalize metadata, rank candidates for the current runtime and prepare evidence-backed acquisition decisions.

## Boundary

Discovery is read-only. Download, import and mount are separate governed actions. Never treat a search result, filename or model card as proof that an artifact is safe, licensed, compatible or authentic.

## Core loop

`SCOPE → DISCOVER → NORMALIZE → DEDUPLICATE → VERIFY SOURCE → LICENSE CHECK → INTEGRITY PLAN → COMPATIBILITY → RANK → APPROVAL → ACQUIRE/MOUNT`.

## Completion

A candidate is READY only when the requested action is supported by evidence. Discovery alone never claims that a model was downloaded, verified or mounted.
