# OMEGA Lovable Assurance MCP

Deterministic assurance companion for Lovable workflows. It does not impersonate the Lovable provider or publish projects itself.

## Tool

`omega_lovable_assurance`

Actions:
- `secret-placement`
- `verification-plan`
- `security-release-gate`
- `revert-impact`
- `design-system-adherence`

The server converts supplied project evidence into deterministic gates. Live project files, security scan results, database queries, connector state, builds and publishing still require the real Lovable provider surface and its current permissions.
