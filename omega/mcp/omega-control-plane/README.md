# OMEGA MCP Control Plane v24

OMEGA v23 adds `omega_assurance_architect`, an internal assurance surface for agent-oriented CI/CD and AI artifact releases.

## New guarantees scoped to supplied evidence

- workflow supply-chain audit and immutable third-party Action refs;
- landing lanes, protected-path parking and policy non-loosening;
- bounded agent reliability contracts;
- AI artifact diff/HOLD decisions;
- MCP behavioral grade/evidence gate;
- governed knowledge with CAS and approval queue;
- work-item scoped session continuity;
- canonical agent sync;
- targeted React Native specialist routing;
- deterministic demo contract and declarative event-agent validation.

External tools are optional adapters and are never fabricated as installed or executed.


## v24 media plane
Adds `omega_media_architect` for ElevenLabs Speech Engine, music, dialogue, SFX, voice isolation/change, forced alignment, dubbing, image/video generation, cost gates and secret-ref-only authentication.
