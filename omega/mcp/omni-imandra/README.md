# OMEGA Omni/Imandra MCP

Narrow stdio projection for deterministic system modelling and counterexample handling derived from the Omni-Architect & ImandraX v2.0 corpus source.

## Tool

- `omega_omni_imandra_model`

Actions:
- `validate-model`
- `counterexample`
- `decision-score`

This server does not orchestrate repositories, mutate projects or fabricate formal proofs. It exposes deterministic model checks only. Actual formal verification remains an external provider boundary.
