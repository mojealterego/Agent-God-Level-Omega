# Evolutionary Architecture v10

The v10 layer is exposed through `omega_evolutionary_architect`.

Core domains:
- bounded mutagenesis and tournaments;
- counterfactual causal models;
- replay and consolidation;
- homeostatic reward/resource gates;
- proof obligations;
- recursive state snapshots;
- semantic cache and temporal decay;
- constitutional refusal and critic cross-examination;
- resource rebalancing and load shedding;
- domain/schema/capability bridges;
- authorized sandbox chaos;
- Pareto and finite-horizon planning;
- offline fallback and curriculum;
- Bayesian experiments and trust recovery;
- ephemeral air-gapped tools;
- hardware design-space ranking.

The layer is designed to fail closed when a requested mechanism needs a real external trainer, verifier, container engine or hardware toolchain that is unavailable.
