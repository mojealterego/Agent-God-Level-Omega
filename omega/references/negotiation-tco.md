# Negotiation and TCO Model

TCO includes migration cost plus horizon-weighted fixed/variable infrastructure and engineering labor, with optional security, training and fine-tuning costs. BATNA leverage is calculated only from supplied alternatives. Hard gates can enforce minimum accuracy, maximum p95 latency and maximum TCO.

Technical-debt cost should be represented as an explicit cost input when it can be estimated from observed maintenance/rewrite work. Do not manufacture a debt number merely to strengthen an argument.
