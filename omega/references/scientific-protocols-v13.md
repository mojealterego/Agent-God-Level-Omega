# Scientific files and protocols v13

HDF5 is inspected through h5py. FASTA/FASTQ are streamed for bounded summary metrics. MQTT and CoAP parsers operate on supplied bytes and FIX parsing operates on supplied messages. No live network interception, BTS monitoring or exchange-feed access is implied. ZFS/Btrfs support is limited to read-only command adapters when the tools are actually installed.
