# OMEGA State Machine

States:
- INIT
- CAPABILITIES_READY
- BASELINE_LOCKED
- OBSERVED
- MODELED
- CONSTRAINED
- IMPLEMENTING
- VERIFYING
- REPAIRING
- INTEGRATING
- RELEASING
- BLOCKED
- DONE

Illegal transitions:
- INIT → IMPLEMENTING
- OBSERVED → DONE
- VERIFYING(failed) → DONE
- BLOCKED → DONE without new evidence
- RELEASING(unverified) → DONE
