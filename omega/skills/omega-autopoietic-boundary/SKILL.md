# Autopoietic Boundary Control

Use `boundary-authorize` and `boundary-manifest` to classify core versus environment paths and hash selected source files. Protected core mutation requires the explicit approval state supplied by the governing workflow.

The boundary is a software integrity/alignment mechanism, not biological autopoiesis. It prevents mutation scope from silently expanding into security/evidence policies.
