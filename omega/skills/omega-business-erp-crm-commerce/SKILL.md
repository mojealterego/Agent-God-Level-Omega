# Business, ERP/CRM and Commerce

Use cost/TCO tools for estimates, the existing service-discovery/MCP federation layer for connected SaaS or enterprise systems, and dynamic knowledge records for source-bearing tax/accounting rules. An ERP/CRM integration is only real when a concrete SAP, Salesforce or other endpoint/connector and credentials are available; the skill does not invent access. Logistics documents should be parsed as files or API records with validation. Marketing or market-sentiment claims should identify the underlying data source and timestamp. Financial/tax decisions are high-impact and should pass the domain-evidence gate and appropriate human review. The goal is auditable workflows, not generic “business instinct”.
