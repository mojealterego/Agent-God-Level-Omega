# Cost Estimation and Commercial Intuition

Call `omega_practical_architect` action `cost-estimate` with quantity plus optimistic, most-likely and pessimistic unit costs. The engine applies the PERT expectation `(O + 4M + P) / 6`, aggregates variance and adds only an explicitly supplied contingency rate. Combine this with OMEGA negotiation/TCO/BATNA skills when comparing vendors, cloud providers, materials, installation work or project alternatives. Keep taxes, discounts, freight, labour rates and currency conversion as explicit sourced inputs rather than guesses. The module is decision support, not a licensed valuation or statutory cost schedule. Preserve the item-level assumptions so a future estimate can be recomputed when prices change and never present a point estimate as certainty when the variance is material.
