# Critical Thinking, Simplicity and Red Teaming

Use before introducing an LLM, agent framework, distributed component, custom abstraction or expensive infrastructure.

Apply the simplest mechanism that satisfies the observed requirements. Compare a deterministic rule, conventional algorithm or smaller model against an LLM/agent when both are plausible. Penalize unnecessary dependencies, state, network boundaries and operating burden in the decision matrix.

For threat and correctness analysis combine `omega_synthetic_red_team`, `omega_reasoning` adversarial gating and `trace-audit`. A structured decision trace must bind factual claims to evidence; private chain-of-thought is neither requested nor audited.

Reject hype-driven claims that lack benchmark, runtime, documentation or production evidence.
