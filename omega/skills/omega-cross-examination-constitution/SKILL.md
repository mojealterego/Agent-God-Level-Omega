# Cross-Examination and Constitutional Refusal

For an important claim, collect verdicts from independent critics or verifiers and compare both conclusion and evidence. A mixed ACCEPT/REJECT result is `CONTESTED`; do not collapse disagreement into a fabricated consensus.

For destructive/high-impact actions, apply constitutional rules that define whether the action is allowed, denied or requires multiple distinct approvals. Typical protected actions include deleting the knowledge base, rewriting shared Git history and destructive production changes.

Actions: `cross-examine`, `constitution-decide`.

Constitutional refusal is a safety gate, not an excuse to ignore ordinary authorized engineering work. Approval tokens must represent real approvals available through the host workflow; never manufacture them.
