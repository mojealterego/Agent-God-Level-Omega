# Source synthesis — DGM self-evolution

Primary corpus source: **Architektura Autonomicznego Systemu DGM.PDF**.

The source proposes a swarm topology containing model discovery, technology reconnaissance, roadmap synthesis and a Darwin-Gödel Machine executor. It also proposes Hugging Face/GitLab integration, broad model discovery, generated application factories and direct code mutation.

OMEGA keeps the useful architecture but changes the execution contract:

- internet/model reconnaissance becomes evidence collection, not automatic trust;
- candidate improvements become falsifiable hypotheses;
- direct self-mutation is replaced by bounded patch plans in isolation;
- every candidate is evaluated against a frozen baseline;
- CI, security, provenance, rollback and approval are mandatory landing gates;
- untrusted model binaries are never mounted merely because a crawler found them.

This preserves the continuous-improvement objective while making the loop auditable and regression-safe.
