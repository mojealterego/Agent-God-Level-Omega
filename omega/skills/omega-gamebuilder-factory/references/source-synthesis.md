# Source synthesis — GameBuilder Factory

Primary corpus source: **Architektura Autonomicznego Systemu DGM(1).PDF**.

The source requests a GameBuilder SDK and sketches modules such as PhysicsEngine, SpriteRenderer and StateOrchestrator. OMEGA maps that factory concept onto the existing game-specialist team rather than duplicating specialist agents.

The GameBuilder Factory owns composition: engine/platform selection, core-loop definition, module dependency graph, asset-rights checks, performance budgets, routing to specialists and verification criteria.
