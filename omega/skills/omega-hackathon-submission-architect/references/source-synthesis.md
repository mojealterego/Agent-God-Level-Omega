# Source synthesis — General Learning Hacks

Primary corpus source: **Analiza zasad hackathonu General Learning Hacks.PDF**.

Reusable requirements extracted from the source:
- a constrained event build window;
- transparent separation of pre-event and event-created work;
- external libraries/APIs may be allowed when declared;
- a working prototype can be mandatory while mockups/decks alone are insufficient;
- team and participant eligibility can be strict;
- submission packages can require an architecture description, public repository and short demo video;
- conflicting official deadlines must be surfaced rather than silently resolved.

OMEGA generalizes these into a reusable hackathon compliance engine. Event-specific facts are never hardcoded as permanently current: every new event run must re-verify official rules and deadlines.
