# Multi-Valued Logic

Use Belnap four-valued logic when the system must distinguish TRUE, FALSE, BOTH and NEITHER. Positive and negative evidence are tracked independently, so contradiction is representable without explosion and missing evidence remains distinct from falsity. Use Lukasiewicz operators for bounded [0,1] many-valued conjunction, disjunction, negation and implication.

Do not silently collapse BOTH to true or false. Attach perspective/context outside the truth value when different observers legitimately use different premises. Multi-valued logic is a decision representation, not a license to ignore evidence quality. Escalate high-impact decisions that depend on BOTH/NEITHER states to evidence collection or human review.
