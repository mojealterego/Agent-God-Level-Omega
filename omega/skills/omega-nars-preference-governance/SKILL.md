# NARS Truth Revision and Preference Governance

Use `nars-from-evidence`, `nars-revise` and `nars-choose` to maintain frequency/confidence truth values from explicit evidence.

Use `preference-governance` for consequential actions. It evaluates explicit stakeholder constraints and weights. This is transparent preference governance, not CEV and not a simulation of an idealized future human.
