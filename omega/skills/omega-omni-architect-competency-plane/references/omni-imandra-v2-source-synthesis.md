# Omni-Architect & ImandraX v2.0 source synthesis

Primary corpus source: `Omni-Architect & ImandraX Synthesis Engine — System Prompt v2.0.md`.

The source is absorbed into the existing OMEGA Omni competency plane rather than becoming a parallel orchestrator.

Key additions/confirmations:
- repository-first and evidence-first state discovery before mutation;
- explicit `OBSERVED / VERIFIED / INFERRED / PROPOSED / UNKNOWN` discipline;
- maximum-capability engineering does not justify unnecessary complexity;
- formal verification is an optional real provider boundary, not a fabricated proof;
- critical models define state, inputs, transitions, invariants, pre/postconditions, forbidden states and edge cases;
- counterexamples trigger model revision rather than suppression;
- architecture decisions compare value, complexity, risk and maintainability;
- security, observability, testing, documentation and post-commit reread are first-class gates;
- knowledge ingestion is transformed into reusable concepts/algorithms/architecture implications rather than copied verbatim;
- new-project creation requires reusable value above maintenance/complexity/risk;
- tool operations require target, expected effect, risk, reversibility and verification;
- final output must distinguish actual execution from plans.

The source originally targeted another repository. Only portable engineering principles are imported; repository-specific path assumptions are not.
