# WDA Ω∞ source synthesis

Primary corpus source: `WDA Ω∞.md`.

The source defines WDA as a model-agnostic visual intent compiler rather than a prompt stylist. OMEGA already had the executable WDA runtime and MCP surface, so this corpus batch adds agent/skill traceability rather than another runtime.

Preserved principles:
- explicit reference semantic roles and priority;
- identity firewall and exact subject-count invariant;
- source/locked/transform/constraints/target state model;
- immutable/flexible/modified/removed/added/derived change matrix;
- zero-drift local editing and change budgets;
- spatial, camera, lighting, material, human-realism, kinesiology, edge, shadow, depth and colour coherence;
- anti-invention and exact-text constraints;
- content/form/light/optics/material/colour/style separation;
- semantic priority instead of model-specific numeric prompt weights;
- current-state + new-instruction iterative workflow;
- F1–F13 failure classification, counterfactual validation and smallest-domain correction;
- model-independent semantic schema compiled into provider-specific instructions;
- final validation before accepting a visual result.

No claim is made that a generative image provider itself is deterministic.
