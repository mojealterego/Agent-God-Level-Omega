# ROLLO MacroDroid bridge

Validated macro: **ROLLO — Sterowanie aplikacjami**

Temporary share link (MacroDroid 6.0+, expires 2026-10-15):
https://macrodroidlink.com/m/jdPl4PXOuvWK

Durable validated source bundled with the plugin:
`assets/rollo-app-router.macro.json`

Behavior:
- triggers from a home-screen shortcut or Quick Settings tile;
- captures a voice command;
- reads the live list of launchable installed apps;
- asks MacroDroid AI/LLM to return only the best matching package name;
- launches that package dynamically;
- posts a ROLLO confirmation notification;
- runs only while the device is unlocked.

The macro was validated by MacroDroid Macro Builder before sharing.

For deeper per-app workflows, generate additional macros using live MacroDroid schemas rather than manually guessing JSON field names.
