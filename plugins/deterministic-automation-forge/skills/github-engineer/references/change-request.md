# Engineering Change Request

```yaml
engineering_change_request:
  repository: owner/name
  source_evidence: []
  requested_behavior: string
  constraints: []
  affected_paths_hint: []
  acceptance_criteria: []
  forbidden_changes: []
  verification_plan: []
```

Only populate fields from observed Intercom/site evidence, repository evidence, or explicit user instructions. Unknown implementation details remain open until repository inspection resolves them.
