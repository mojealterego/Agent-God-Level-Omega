# Android / mobile contract

OMEGA Tools Fabric is designed for Android, web and desktop.

- No packaged `mcp.json` or `.mcp.json`.
- No local `stdio` prerequisite.
- No Docker/localhost/desktop terminal prerequisite for normal operation.
- Prefer cloud-hosted connected apps with OAuth.
- If a capability is desktop-only, expose it as an optional lane and continue with mobile-capable alternatives where possible.
- Never label a plugin mobile-capable solely because an MCP URL is remote; use real app bindings or host-supported connected apps.
