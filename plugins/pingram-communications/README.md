# Pingram Communications

Cross-platform companion plugin for Pingram's hosted MCP service.

Supported Pingram MCP regions:
- US: `https://mcp.pingram.io`
- Canada: `https://mcp.ca.pingram.io`
- EU: `https://mcp.eu.pingram.io`

The package intentionally contains no `mcp.json` or `.mcp.json` so it does not create a desktop-only dependency. Connect the corresponding Pingram Custom MCP App in ChatGPT and authorize it with the same Pingram account used in the dashboard.
