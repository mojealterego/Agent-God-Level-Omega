# Capability boundary

Documented hosted MCP capabilities include:
- email sends
- SMS sends
- delivery log lookup by tracking ID
- phone-number search/purchase/listing
- sender-domain management
- email inbox management
- account creation / US A2P 10DLC brand-registration workflows

Pingram also documents inbound email/SMS at the product/API level. Use inbound-related actions only when corresponding live MCP tools exist.

Voice and WhatsApp must not be assumed active in this plugin merely because Pingram product materials mention them. Treat live MCP `tools/list` as authoritative.
