# ROLLO S24 Ultra Agent

Android-first orchestration agent for the user's Samsung Galaxy S24 Ultra.

Execution layers:
1. verified ChatGPT app connectors;
2. MacroDroid / Android local automation;
3. Protected Mode for finance, identity, authentication and health.

The package contains no `mcp.json` or `.mcp.json` and does not require a PC, Docker, localhost or `stdio` for normal use.
