# ROLLO security boundaries

## Never automate final authorization
- bank transfers and card payments
- PayPal/Revolut/PaysafeCard confirmation
- mObywatel identity confirmation/signing
- OTP, 2FA, authenticator codes
- Samsung Pass/passkeys/password submission
- biometric approval or PIN entry
- irreversible account deletion
- health-data disclosure to third parties

## Require explicit confirmation
- posting publicly to social media
- sending a message to a new recipient when content/identity is ambiguous
- purchases, subscriptions, in-app purchases, game spending
- account/privacy/security setting changes
- deleting cloud files, messages, contacts or media

## Safe autonomous actions
- launching apps
- searching/browsing read-only content
- drafting content
- opening navigation/maps
- preparing calendar events before a provider write
- organizing files when the destination is clear and reversible
- showing summaries and reminders
